
# LazyBasics
A module for doing basic arithmetic for the sake of using a module
<
(Currently only available for Lua)
### How to use in project:

1. Download the file and put it in your project folder.
2. Reference it on your main script ~>

    `local lb = require(lua.lazybasics)`

The module supports the 4 basic arithmetic operations ~>

`add(x , y)`

`subtract(x , y)`

`multiply(x , y)`

`divide(x , y)`

### Note: I made this to see how modules work in Lua. I do not recommend using this for obvious reasons.
